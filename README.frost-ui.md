# Frost UI — Pi Agent

OpenChamber-inspired VS Code UI for Pi Coding Agent.

Fork of [frostime/pi-vscode-ui](https://github.com/frostime/pi-vscode-ui) (AGPL-3.0).
Visual language adapted from [openchamber/openchamber](https://github.com/openchamber/openchamber) (MIT).

Build: `pnpm install && node scripts/build.mjs && node scripts/package-vsix.mjs`
